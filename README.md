# Quarantine
Quarantine is a survival horror game where you're stuck inside a building while something waits outside. Your job is to survive by keeping doors and windows secured and making sure you don't leave anything open for whatever is out there to find. If something does get in, you fight it to protect youself and the room!

# Features
- Pixel-art environment and atmospheric visuals
- Survival-focused gameplay
- Jumpscares and overlay effects
- Interactive game and many minigames
- Audiooo
- Canvas-based game rendering

## Getting Started

### Dependencies

You'll need:

- Node.js
- npm
- A modern web browser

### Installing

1. Clone the repository:

```bash
git clone https://github.com/keerts08/quarantine
```

2. Navigate into the project directory:

```bash
cd quarantine
```

3. Install the dependencies:

```bash
npm install
```

### Executing

Start the development server:

```bash
npm run dev
```

Open the local URL shown in your terminal (usually `http://localhost:3000`) to access qarantine.

## Help

If the project doesn't start, make sure Node.js is installed and that you've run `npm install` inside the project directory. If a port is already in use, stop the other process using it or let the development server choose another port.
